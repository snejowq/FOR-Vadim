# Как запустить тесты Google Test в Visual Studio (Windows)

Решение уже готово: проект `LR2Tests` создан и настроен, Google Test подключается NuGet-пакетом автоматически.

1. Скопируй всю папку `БОНУС_2026_Kurlenia` на компьютер с Windows (флешка/облако).
2. Нужна Visual Studio 2022 с компонентом **«Разработка классических приложений на C++»** (в Visual Studio Installer).
3. Открой **`БОНУС_2026_Kurlenia.sln`** двойным кликом.
4. При первой сборке Visual Studio сама скачает NuGet-пакет Google Test (нужен интернет один раз). Если появится вопрос про восстановление пакетов или перенаправление toolset (например, если у тебя VS 2019) — соглашайся (OK / Retarget).
5. Меню **Сборка → Собрать решение** (Ctrl+Shift+B).
6. Меню **Тест → Обозреватель тестов** → кнопка **Выполнить все тесты**. Должно быть 23 зелёных галочек. Скриншот — результат для преподавателя.
7. Если нужен вывод в чёрном окне: правый клик по проекту `LR2Tests` → «Назначить запускаемым проектом», затем Ctrl+F5. Там будет `[  PASSED  ] 23 tests.`
8. Для скриншота с ошибкой: в `test.cpp` поменяй, например, `"2 * 2 * 3"` на `"2 * 3 * 2"`, пересобери и запусти (будет красный крестик и сообщение о том, что ожидали и что получили). Сделай скриншот и верни как было.

## Запасной способ (если готовое решение не открылось/не собралось)

1. В Visual Studio: правый клик по решению → Добавить → Создать проект → шаблон **Google Test** (если шаблона нет — в Visual Studio Installer добавь «Тестовый адаптер для Google Test» в составе «Разработка классических приложений на C++»). Назови, например, `LR2Tests`.
2. В созданном проекте удали файл-пример `test.cpp` (правый клик → Удалить).
3. Правый клик по проекту → Добавить → Существующий элемент → выбери `lab2_functions.h` и `test.cpp` из папки `LR2Tests` этой папки.
4. Если в твоём созданном проекте нет `pch.h` — удали строку `#include "pch.h"` в начале `test.cpp`.
5. Дальше то же самое: пункты 5–8 сверху.

Структура файлов:

- `БОНУС_2026_Kurlenia.sln` — решение, открывать его
- `LR2Tests/LR2Tests.vcxproj` — проект с тестами (тесты из лаб ЛР2: 1.7, 2.4, 3.10)
- `LR2Tests/lab2_functions.h` — функции из лаб
- `LR2Tests/test.cpp` — 23 теста Google Test
- `logs/` — примеры вывода (все тесты прошли / один упал)
